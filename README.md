A lightweight, real-time LiDAR perception pipeline for autonomous vehicles and robotics. Combines KD-tree geometric clustering and a PointNet++-style deep network for 7-class semantic segmentation, then rasterizes points into a foveated 2.5D occupancy grid — three concentric rings of increasing cell size with distance — cutting memory use by over 90% versus a uniform grid while preserving near-field detail. Includes synthetic/SemanticKITTI data sources, a live UDP sensor bridge, Streamlit + Plotly dashboard, and full benchmarking (latency, memory, accuracy by distance). Built for Smart India Hackathon 2026 (problem statement SIH26053).
